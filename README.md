# agentes-ia

Python project managed with [uv](https://docs.astral.sh/uv/) (Python version, dependencies, and virtual environment).

## Requirements

- [uv](https://docs.astral.sh/uv/getting-started/installation/) installed

## Setup

1. Clone the repository and enter the folder:

   ```bash
   git clone git@github.com:KaduMelo/agentes-ia.git
   cd agentes-ia
   ```

2. Create the virtual environment and install the dependencies (read from `pyproject.toml` / `uv.lock`):

   ```bash
   uv sync
   ```

   uv automatically downloads the Python version set in `.python-version` (3.14) if it's not installed yet, and creates the `.venv/` folder in the project root.

3. Activate the virtual environment:

   ```bash
   source .venv/bin/activate
   ```

   To deactivate it, run `deactivate`.

## Running the project

With `.venv` activated:

```bash
python main.py
```

Or, without activating the venv manually, using `uv run` (it resolves the environment automatically):

```bash
uv run main.py
```

## Managing dependencies

```bash
uv add <package>       # adds a dependency (updates pyproject.toml and uv.lock)
uv remove <package>    # removes a dependency
uv sync                # syncs the .venv with what's in the lock file
```

## Project structure

```
.
├── main.py           # entry point
├── pyproject.toml    # project metadata and dependencies
├── uv.lock            # dependency lock file (generated by uv)
└── .python-version    # Python version used by uv
```
